# تأثير · تجربة المشاركة في الحملات (Mobile prototype)

بروتوتايب mobile-first لتجربة اكتشاف الحملات والمشاركة فيها، مبني على هوية موقع **تأثير** نفسه (tatheer.marketing): ثيم فاتح، بنفسجي `#7552FE`، أزرار كبسولة لامعة، RTL ولهجة سعودية، وأنواع الحملات الثلاثة (عامة / توصيات / موقعية) والدفع على النتيجة (لكل نقرة). الصور من موقع تأثير.

## تشغيل المشروع

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build → dist/
```

النشر: ارفع المجلد على Vercel/Netlify (Build: `npm run build`، Output: `dist`).

Stack: React 18 + Vite + Framer Motion. بدون backend، كل البيانات mock في `src/data.js`.

## الفلو

1. **اكتشف**: فلتر (الكل / ريلز / قصص / تجربة منتج)، كاروسيل مميّز، «حملات لك»، «الأعلى أجرًا».
2. **تفاصيل الحملة**: الأجر، الميزانية الحيّة، آلة حاسبة للأرباح، المطلوب والممنوع، ثم «ابدأ الإعلان».
3. **المشاركة في 4 خطوات** (كانت 5 + تنقّل بين شاشات):
   - اختر المنصة ← جهّز المحتوى (قائمة تحقق + وصف جاهز) ← انشر (رابط خاص بنسخة واحدة + أزرار فتح التطبيق) ← الصق رابط المنشور.
   - فحص بالـ AI (محاكى) ثم شاشة النجاح بالأرباح.
4. **حملاتي / المحفظة**: عدّاد نقرات حيّ بعد الاعتماد.

## Design rationale

- **دمج الـ brief في صفحة الحملة بدل خطوة مستقلة.** المستخدم يقرأه قبل ما يقرر، فما نحتاج نعيد عرضه. الفلو صار 4 خطوات بدل 5.
- **الأرباح أولًا.** الأجر لكل 1000 نقرة ظاهر في كل كرت، وآلة حاسبة تحوّل «النقرات» لريالات. الناس العاديين يفهمون الفلوس، مو الـ CPM.
- **لغة بدون مصطلحات.** «referral URL» و«bio» صارت «رابطك الخاص» و«البايو» مع خطوات مرقّمة بسيطة.
- **أصعب لحظتين مبسّطتين:** النسخ (زر واحد للرابط وزر للوصف الجاهز، مع feedback فوري) والإثبات (لصق تجريبي + فحص AI يبيّن للمستخدم وش يتحقق منه بدل انتظار غامض).
- **قائمة تحقق قبل النشر** تقلل رفض المنشورات لأن المستخدم يعلّم على كل شرط وهو يصوّر.
- **حركة بمعنى:** مؤشر الفلتر ينزلق (shared layout)، التقدّم يتعبّى شريطًا شريطًا، الفحص يبيّن كل شرط وهو يكتمل، والاعتماد يطلق confetti وعدّاد أرباح. وكل الحركة تتعطل مع `prefers-reduced-motion`.
- **الشكل:** Dark UI مثل المرجع، أغلفة حملات مولّدة بـ CSS (بدون صور خارجية)، شارات خضراء للأجر، شريط تنقل عائم، وخط IBM Plex Sans Arabic.

## هيكل الكود

```
src/
  data.js      بيانات الحملات والمنصات (mock)
  App.jsx      التنقل والحالة العامة
  Discover.jsx صفحة الاكتشاف
  Detail.jsx   تفاصيل الحملة + الحاسبة
  Flow.jsx     خطوات المشاركة + الفحص + النجاح
  Tabs.jsx     حملاتي والمحفظة
  Shared.jsx   Cover و CountUp وأدوات مشتركة
```

## ما هو محاكى

فحص الـ AI، فتح التطبيقات، عدّاد النقرات، والمحفظة كلها محاكاة. رابط التحقق يقبل أي رابط من المنصة المختارة، وزر «لصق تجريبي» يعبّي رابط جاهز.
